# Android Spam Filter

Dismiss Google Messages notifications whose message preview contains one of your saved keywords. The same rules apply to SMS and RCS. Matching uses case-insensitive substrings and runs on your phone.

1. Open Spam Filter and add a word or phrase. An in-place upgrade keeps your existing keyword list.
2. Tap **Notification access settings** and enable access for **Spam Filter**.
3. Keep using Google Messages. When it posts a conversation notification, Spam Filter checks the newest message preview and dismisses the notification if it matches.

Android dismisses the whole conversation notification, which may contain several unread messages. Messages stay in Google Messages, and the phone may already have sounded or vibrated. Filtering requires text in the notification preview. You can turn it off in notification access settings.
